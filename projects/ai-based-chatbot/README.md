# 🤖 AI-Based Chatbot Application

A chatbot application developed to automate responses to common user queries and improve response turnaround for end users.

## 🧰 Technologies

- Java
- Spring Boot
- REST API

## ✨ Key Features

- Automates responses to common user queries
- Uses Spring Boot for backend application development
- Exposes functionality through REST APIs
- Applies object-oriented programming principles
- Focuses on modular and maintainable code

## 🎯 Project Objective

The goal of the project is to provide automated responses for common queries and improve the response experience for users.
